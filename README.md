# Lesson-OB-06-Fight-and-Weeek
# Игра "Бой" (Консольная игра)

Этот скрипт представляет собой простую текстовую игру, в которой игрок сражается с компьютером. Каждый из участников обладает здоровьем и силой атаки. Игра продолжается, пока один из участников не погибнет.

## Зависимости

Для запуска игры не требуется дополнительных зависимостей, все реализовано с использованием стандартных библиотек Python.

## Как использовать

1. Запустите скрипт:
    ```bash
    python main.py
    ```

2. Игра начнется автоматически. Игрок и компьютер по очереди наносят удары друг другу. После каждого удара выводится информация о текущем здоровье каждого участника.
3. Игра завершится, когда один из участников погибнет. Программа объявит победителя.

### Пример вывода:


Игра началась!
Бой атакует Компьютер на 20 урона.
Здоровье Компьютер: 80
Компьютер атакует Бой (консоль) на 20 урона.
Здоровье Бой (консоль): 80
...


### Описание классов
#### Класс Hero
Этот класс описывает персонажа, который может атаковать другого персонажа и иметь здоровье:

Методы:
__init__(self, name) — Инициализирует персонажа с именем, здоровьем (100) и силой атаки (20).
attack(self, other) — Атакует другого персонажа, уменьшая его здоровье на величину своей силы атаки.
is_alive(self) — Проверяет, жив ли персонаж (здоровье больше 0).

#### Класс Game
Этот класс организует игру между игроком и компьютером:

Методы:
__init__(self, player_name) — Инициализирует игру с именем игрока и компьютера.
start(self) — Запускает игру, проводя поочередные ходы игрока и компьютера, пока один из них не погибнет.

#### Примечания
Игра работает в консольном режиме.
После каждого хода выводится информация о текущем здоровье обоих участников.
Чтобы завершить игру, достаточно просто закрыть окно терминала или прервать выполнение программы.
